# ECD complete recording checklist

Generated by `npm run ecd:audio` from the game scripts. Do not edit this generated sheet.

Record each line into the exact path listed. MP3 can replace WAV with the same filename stem. WAV takes priority when both exist. Use real PCM WAV (16-bit, mono, 44.1 or 48 kHz), not an MP3 renamed to WAV. Directions in square brackets are performed, not spoken.

After adding recordings, restart `npm run dev` or run `npm run build` before deploying. Both refresh the audio index automatically. Missing narration uses browser speech where available; missing effects are silent. No API keys or audio conversion are required for individual clips.

Individual number files 0–20 work without timestamp mapping. Existing combined numbers recordings remain supported; run `npm run numbers:map -- public/sounds/ecd/maths/numbers.wav` after replacing that recording.

Existing recording guides: [maths](ECD_MATHS_VOICE_SCRIPTS.md), [reading](ECD_READING_VOICE_SCRIPTS.md), [phonics](ECD_PHONICS_VOICE_SCRIPTS.md). Optional music and sound effects: [asset guide](ECD_MATHS_SOUND_ASSETS.md). All ECD effects accept WAV or MP3 under the same filename stem.
