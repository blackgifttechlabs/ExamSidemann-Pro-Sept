# Practical Labs — ChatGPT Image Prompts

These prompts are for images used by the desktop Practical Labs gaming-style page. Generate each image separately and save it at the exact path shown. Do not add text, logos, badges, buttons, watermarks, or interface elements inside the artwork; the website supplies those in HTML so they stay responsive and accessible.

## Shared visual direction

Use this direction for every image below:

- Premium stylized 3D educational game artwork, suitable for secondary-school learners.
- A clean, safe, modern virtual laboratory—not a casino, nightclub, or violent game.
- Realistic apparatus proportions and scientifically credible arrangements, simplified enough to read instantly at card size.
- Materials should have convincing depth: brushed metal, clear glass, glossy plastic, rubber, liquid and soft LED light.
- Palette: deep violet, indigo and midnight blue environments, accented with cyan, magenta, amber and clean white laboratory light.
- Cinematic but clean lighting, soft volumetric glow, controlled reflections, rounded shapes and crisp silhouettes.
- Diverse, inclusive representation if hands or people appear. Use correct PPE: safety glasses, lab coat and tied-back hair where relevant.
- No identifiable brands, copyrighted characters, logos, flags or institution names.
- No gambling imagery, playing cards, coins, weapons, fire hazards, broken glass, spills, injury, frightening faces or unsafe laboratory behaviour.
- No embedded text, letters, equations, labels, numbers, UI, watermark or border.
