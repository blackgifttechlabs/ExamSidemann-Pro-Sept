Created with the built-in image_gen tool using the imagegen skill. Eleven separate landscape raster images, 1536 × 1024, encoded as WebP for the lesson. Generated PNG originals remain in the tool output directory. No SVG or programmatically drawn replacements.

Scientific checks: resultant arrows match force direction; moments use perpendicular distance and N m; first-class beam forces produce opposite moments; friction opposes sliding; pulley rope supports the movable load; gears counter-rotate; pressure arrows indicate exit speed rather than landing distance; manometer gas-side level is lower; siphon outlet is below the source surface; hydraulic oil transmits pressure; pump flow follows the stated valve states. The Blair image is a simplified hollow-pushrod teaching model.
