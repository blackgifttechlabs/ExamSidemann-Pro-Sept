# Form 4 Combined Science artwork

Drop the Form 4 Biology, Chemistry and Physics illustrations here.

File names are fixed — they are already referenced by
`components/courses/o-level/form-4/combined-science/LearningOutcome{1,2,3}.tsx`.

The complete list of file names, plus a drawing prompt for each one, is in
[`docs/FORM4_COMBINED_SCIENCE_IMAGE_PROMPTS.md`](../../../../../../docs/FORM4_COMBINED_SCIENCE_IMAGE_PROMPTS.md).

Until a file exists the lesson simply hides that figure, so images can be added
in any order without breaking the pages.
